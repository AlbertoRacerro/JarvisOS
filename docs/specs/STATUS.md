# Spec status and roadmap

Status: **canonical live registry**

The single registry of **open** specs: status, hard dependencies and implementation-PR association. It is not a prompt,
a review policy or a scheduling queue; PR diffs list the files a spec touches, and a spec file's own `Status:` line is not
authoritative. Merged and cancelled rows are pruned together with their spec files, so a hard dependency on a spec that is
no longer listed is satisfied.

Status values, the transition rules and the PR "Spec gate" line are defined in `docs/PROCESS.md` (section "Specs") and
enforced by `scripts/check_spec_status.py`. `planned` never authorizes implementation.
